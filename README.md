# PHẦN MỀM TRẮC NGHIỆM TIẾNG ANH: PREPOSITIONS (20 CÂU HỎI)
### TRƯỜNG CAO ĐẲNG CÔNG NGHỆ THỦ ĐỨC (TDC)

Ứng dụng web trắc nghiệm trực quan, hiện đại gồm 20 câu hỏi trọng tâm chuyên đề **Prepositions (Giới từ trong tiếng Anh)**.

---

## 🌟 ĐẶC ĐIỂM NỔI BẬT THEO YÊU CẦU

1. **Chuẩn 100% 20 câu hỏi theo đề bài yêu cầu**:
   - Trọn bộ 20 câu hỏi kiểm tra đầy đủ các cụm giới từ, tính từ + giới từ, động từ + giới từ kinh điển:
     1. Cụm cố định: `in danger of extinction` (nguy cơ tuyệt chủng)
     2. Cặp giới từ: `quick at understanding`, `capable of remembering`
     3. Tính từ + giới từ: `suitable for the position`
     4. Động từ + giới từ: `explain something to somebody`
     5. Cấu trúc câu cảm thán/nhận xét: `generous of you to lend...`
     6. Động từ xin lỗi: `apologize for (doing) something`
     7. Thành ngữ: `by chance` (tình cờ = by accident)
     8. Động từ tán thành: `approve of hunting animals`
     9. Tính từ bắt buộc: `compulsory for all children`
     10. Cấu trúc so sánh sở thích: `prefer wearing modern clothing to traditional clothing`
     11. Động từ và thành ngữ: `agree with you`, `at once`
     12. Tính từ chịu trách nhiệm: `responsible for keeping the environment...`
     13. Động từ làm đầy: `fill the glass with cold water`
     14. Tính từ chán ngấy: `tired of doing this work`
     15. Phrasal verb: `turn into a big fight`
     16. Cấu trúc kết án: `convicted of theft`
     17. Tính từ so sánh khác biệt: `different from other classes`
     18. Tính từ cảm xúc: `satisfied with their progress`
     19. Động từ phụ thuộc: `depends on your position`
     20. Động từ phân biệt: `distinguish between red and green`

2. **Logo TDC ở trên cùng góc trái**:
   - Logo chính thức của Trường Cao đẳng Công nghệ Thủ Đức (`tdc_logo.png`) được đặt ở góc trên bên trái thanh điều hướng với độ sắc nét cao.

3. **Bố cục tối ưu đặc biệt cho Điện thoại & iPad**:
   - **Khung câu hỏi đặt bên dưới cùng (Bottom-docked card)** khi hiển thị trên điện thoại hoặc iPad.
   - **Đảm bảo câu hỏi và tất cả các lựa chọn (A, B, C, D) cùng nằm gọn trong 1 khung duy nhất**, không bị tách rời hay trôi layout, giúp sinh viên thao tác bằng ngón tay cái rất thoải mái và nhanh chóng.

4. **Bảo mật khi làm bài & Xem giải thích chi tiết sau khi nộp**:
   - **Lúc làm bài**: Tuyệt đối **không** hiển thị bất kỳ gợi ý, cờ đúng/sai hay đáp án nào bên cạnh câu hỏi.
   - **Sau khi nộp bài**: Kích hoạt chế độ Xem lại (Review Mode):
     * Làm nổi bật đáp án đúng (màu xanh lá kèm huy hiệu `✓ Đáp án đúng`).
     * Hiển thị lựa chọn của sinh viên nếu chọn sai (màu đỏ kèm huy hiệu `✗ Lựa chọn của bạn`).
     * Khung **Giải thích chi tiết & Dịch nghĩa** hiển thị ngay trong khung câu hỏi:
       - 🇻🇳 **Dịch nghĩa**: Dịch nghĩa trọn vẹn ngữ cảnh câu hỏi sang tiếng Việt chuẩn xác.
       - 📚 **Giải thích ngữ pháp**: Phân tích chi tiết quy tắc từ loại, cấu trúc giới từ, collocations vì sao lại dùng đáp án đó.
     * Nút **"Xem trọn bộ 20 câu"** cho phép sinh viên xem toàn bộ danh sách 20 câu hỏi kèm đáp án và giải thích trên một trang duy nhất.

5. **Theo dõi số lượng người đăng nhập và truy cập khi đưa lên GitHub**:
   - **Bộ đếm trực tiếp (Live Visitor Counter)**: Hiển thị ngay trên thanh điều hướng số lượt người truy cập vào hệ thống (tự động đồng bộ qua API đám mây khi triển khai online).
   - **Hệ thống đăng nhập thông tin sinh viên**: Sinh viên có thể nhập Họ tên, Mã số sinh viên (MSSV) và Lớp học phần trước khi làm bài.
   - **Bảng Thống kê & Quản trị dành cho Giảng viên (Admin Dashboard)**:
     * Nhấp vào nút `📊 Thống kê` trên góc phải.
     * Thống kê tổng số lượt truy cập link, số lượt đã nộp bài, điểm trung bình của sinh viên.
     * Bảng danh sách chi tiết từng sinh viên: Họ tên, MSSV, Lớp, Điểm số (trên 20), Thời gian làm bài, Ngày giờ nộp bài.
     * **Nút xuất Excel (`📥 Tải về file Excel (CSV)`)**: Giảng viên có thể tải về file bảng điểm lớp đầy đủ chỉ với 1 cú click!
   - **Theo dõi qua GitHub Insights**: Hướng dẫn chi tiết cách xem biểu đồ người dùng thực tế trên GitHub Traffic.

6. **Các tiện ích khác**:
   - Bộ chuyển đổi nhanh chế độ xem **PC / iPad / Mobile** ngay trên màn hình để kiểm tra giao diện.
   - Đồng hồ đếm thời gian làm bài.
   - Chế độ Sáng / Tối (Light Mode / Dark Mode).
   - Phím tắt tiện lợi trên máy tính (`←` / `→` để chuyển câu; `1, 2, 3, 4` hoặc `A, B, C, D` để chọn đáp án).

## 🚀 HƯỚNG DẪN CHẠY TRÊN MÁY LOCAL (MÁY TÍNH CÁ NHÂN)

### Cách 1: Chạy bằng file Batch (Khuyên dùng - 1 Click)
1. Mở thư mục `d:\websiteabc\PREPOSITIONS`
2. Nhấp đúp chuột vào file **`run_local.bat`**
3. Trình duyệt mặc định sẽ tự động mở trang web tại địa chỉ: `http://localhost:8080` (hoặc `8081` nếu cổng đang bận).

### Cách 2: Mở trực tiếp file HTML
1. Nhấp đúp chuột trực tiếp vào file **`index.html`**.
2. Ứng dụng sẽ chạy ngay lập tức trên trình duyệt mà không cần cài đặt thêm bất kỳ phần mềm nào.

## 🌐 HƯỚNG DẪN ĐƯA LÊN GITHUB PAGES & THEO DÕI NGƯỜI ĐĂNG NHẬP

### Bước 1: Tạo Repository trên GitHub
1. Đăng nhập vào [GitHub](https://github.com/) của bạn.
2. Bấm nút **New Repository** (Tạo repo mới).
3. Đặt tên, ví dụ: `tdc-prepositions-quiz`. Chọn chế độ **Public** và bấm **Create repository**.

### Bước 2: Tải code lên GitHub
Mở PowerShell tại thư mục này và chạy các lệnh:
```powershell
cd "d:\websiteabc\PREPOSITIONS"
git init
git add .
git commit -m "Initial release of TDC Prepositions Quiz"
git branch -M main
git remote add origin https://github.com/<tai-khoan-github-cua-ban>/tdc-prepositions-quiz.git
git push -u origin main
```

### Bước 3: Kích hoạt GitHub Pages
1. Vào repository trên GitHub > Chọn tab **Settings** (Cài đặt).
2. Tại menu bên trái, chọn **Pages**.
3. Ở mục **Build and deployment > Branch**, chọn branch **`main`** và thư mục **`/(root)`**, sau đó bấm **Save**.
4. Chờ khoảng 1-2 phút, GitHub sẽ cấp đường link dạng:
   `https://<tai-khoan-cua-ban>.github.io/tdc-prepositions-quiz/`
5. Gửi link này cho sinh viên làm bài trên điện thoại hoặc máy tính.

### Bước 4: Xem số lượng người truy cập vào link trên GitHub
Giảng viên có thể theo dõi người truy cập bằng 2 cách:
1. **Trực tiếp trên website**: Nhìn vào badge `Truy cập: [Số]` ở góc trên hoặc nhấp nút `📊 Thống kê` để xem danh sách sinh viên nộp bài và xuất file Excel.
2. **Trên trang quản lý của GitHub**:
   - Truy cập vào repo GitHub của bạn.
   - Nhấp vào tab **Insights** (Thông số chi tiết) > Chọn mục **Traffic** (Lưu lượng truy cập).
   - Tại đây GitHub sẽ hiển thị biểu đồ chính xác:
     * **Visitors (Khách truy cập duy nhất)**: Số lượng người/thiết bị khác nhau đã vào link.
     * **Views (Lượt xem)**: Tổng số lần trang web được mở hoặc tải lại.
